# Archived experiments

Superseded lab-box recipes and standalone explorations. Findings are preserved
in memory and git history; nothing here is deleted, just moved out of the way.

Top-level `experiments/` is reserved for the paper spine (`paper_campaign/`) and
its live dependencies (`turbine_modification/` feeds `02_diameter_family`;
`utide_parity/` is the pipeline's tidal-harmonic validation).

Two kinds live here:
- **Superseded recipes** — curated versions run inside `paper_campaign/03–05`:
  `rated_cutin_sweep/`, `spatial_clustering/`, `max_energy_objective/`,
  `transmission_stepup/`.
- **Standalone findings** — recorded in memory but not carried into the paper:
  `velocity_distribution/`, `full_grid_currents/`, `scope_x_scale/`,
  `site_spacing_map/`, `east_coast_cf_map/`, `east_coast_domain/`,
  `uncertainty_mc/`.
